### Synthetic Population Generation

Undergraduate thesis project focused on generating synthetic population data using CTGAN and Iterative Proportional Fitting (IPF).

The project implements an end-to-end pipeline covering data preprocessing, synthetic data generation, calibration against aggregate population constraints, integerization, and statistical evaluation.

**Pipeline**

`Preprocessing → CTGAN → IPF Calibration → Integerization → Evaluation`

**My contribution**

- Developed the data preprocessing and harmonization workflow
- Implemented and evaluated missing-value imputation approaches
- Developed the CTGAN training and synthetic data generation workflow
- Implemented Iterative Proportional Fitting from scratch for aggregate calibration
- Implemented integerization using Truncated Randomized Systematic sampling
- Developed statistical evaluation and Streamlit visualization components

**Tech stack:** Python · Pandas · NumPy · SciPy · CTGAN · Streamlit

[View Repository](https://github.com/ashidayat-dev/synthetic-population)
